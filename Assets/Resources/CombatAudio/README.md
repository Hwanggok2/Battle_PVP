# 전투 효과음

프로젝트 전용 합성 효과음. 외부 녹음·음원은 사용하지 않았습니다.

- `sword-air-0/1/2.wav`: 0.19 / 0.205 / 0.22초의 짧은 검 스윙음. 빠른 가속, 얇은 고역 절삭음, 저역 바람층과 짧은 감속 꼬리를 겹쳤다. 긴 쉭쉭거림과 전자음 같은 음정 변화는 사용하지 않는다. (2026-09-29 교체)
- `sword-cut-0/1.wav`: 짧은 절삭 소음, 둔탁한 충격, 미세한 금속 잔향을 겹친 타격음.
- `death-discharge.wav`: 낮아지는 저음과 방전 소음을 결합한 사망음.

44.1 kHz, 16-bit PCM, 모노. 생성기: `Assets/Remodel/Editor/CombatSoundBuilder.cs`.
`CombatAudio`가 기존 효과음 음량과 전체 음량을 따릅니다. 검 소리는 애니메이션 타격 창이 열릴 때 1회, 타격음은 실제 피해가 확인된 공격자에게, 사망음은 생사 상태가 전환될 때 재생합니다.
