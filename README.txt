Battle PvP — 2026-10-13 모바일 조작·스텟 유지·WebRTC 개선

게임: https://hwanggok2.github.io/Battle_PVP/?v=20261013-mobile-fixes
호스트와 참가자는 모두 이번 새 버전을 사용해 주세요. 이전 버전과 스텟 동기화 형식이 다릅니다.
Windows 호스트도 새 Windows 빌드로 교체하고, 웹 참가자는 새로고침 후 접속해 주세요.

- 설정 → 모바일: 이동 조이스틱, 공격, 보조 공격, 스킬 1/2, 점프, 앉기의 크기·위치를 각각 조절하고 기기에 저장
- 조이스틱: 고정 위치 또는 터치 위치 생성 선택. 터치 위치 생성은 왼쪽 빈 화면을 누른 지점에 나타나고 손을 떼면 숨김
- 이동과 공격·시점 회전을 여러 손가락으로 함께 조작. 공격 버튼을 누른 채 드래그해도 시점 회전 가능
- 부활 대기 완료 후 화면 중앙 터치로 부활
- Android 전체화면 버튼 / iPhone Safari 공유 → 홈 화면에 추가 → 아이콘으로 실행
- 프리셋을 살펴보는 동작과 실제 적용을 분리하고, 서버가 승인한 스텟을 대기실·전투 씬 전환 후에도 복원
- WebRTC의 오래된 비신뢰성 패킷 적체 완화. 기존 RTT/Jitter와 별도로 ICE 지연·송신 대기량·프레임 최대 간격 표시
- PC 키보드·마우스 조작 유지

검증: 관련 Unity EditMode 고유 163개 및 웹 입력·페이지 셸·WebRTC Node 테스트 30개 통과.
실제 휴대폰의 조작감과 멀티플레이는 별도 검증 대상입니다.
보고된 RTT 1500ms 급등은 실제 기기에서 재측정하지 않았으며 해결 완료나 개선 수치를 확정하지 않았습니다.
재현 시 노트북 호스트와 휴대폰 양쪽의 RTT·ICE·Queue·Frame peak를 함께 확인해 주세요.
가로 화면과 전체화면 버튼 사용을 권장합니다.

GitHub 파일 크기 제한에 맞춰 Unity 데이터 파일을 분할했습니다. 원본 압축 데이터 바이트는 변경하지 않습니다.
